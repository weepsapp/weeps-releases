# Weeps — desktop releases

This repository only hosts **installers** for the Weeps desktop app (closed beta).
There is no source code here.

- Download the latest Windows installer from the [Releases](https://github.com/weepsapp/weeps-releases/releases) page.
- The app updates itself from this repository (`latest.yml`).
- Beta builds are not code-signed yet: Windows SmartScreen may show
  "Windows protected your PC" — choose **More info → Run anyway**.
- Using the app requires a Weeps account with a beta invite.

Contact: contact@weeps.app
